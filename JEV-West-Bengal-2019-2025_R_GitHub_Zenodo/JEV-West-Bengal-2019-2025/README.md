# JEV West Bengal 2019–2025: R Analysis

This repository contains R scripts used for analysis of Japanese encephalitis virus (JEV)
positivity in West Bengal during 2019–2025.

## Contents

- `scripts/01_annual_temporal_trend.R` — annual JEV positivity and temporal-trend figure.
- `scripts/02_year_district_association.R` — association of JEV positivity with year and district using Pearson's chi-square test and Cramer's V.
- `figures/` — publication figures generated by the scripts.
- `data/` — documentation for datasets; sensitive patient-level data should not be placed here unless appropriately de-identified and cleared for public release.

## Reproducibility

Run the scripts in R/RStudio with the required packages installed.

## Data availability

The analysis scripts contain the aggregate values used in the current analysis. Patient-level
clinical data are not included in this repository.
